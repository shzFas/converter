# converter

Telegram-бот: принимает ссылку на YouTube и присылает MP4, MP3 или расшифровку речи, при желании — только фрагмент по таймкодам. Спецификация — в [spec.pdf](spec.pdf).

Сейчас это локальная версия: один процесс на Go, без Docker и без базы данных. Состояние лежит в `data/store.json`, временные файлы — в `tmp/`.

## Запуск

Нужны Go 1.27+, [yt-dlp](https://github.com/yt-dlp/yt-dlp), ffmpeg и Deno (без него yt-dlp плохо работает с YouTube):

```sh
brew install go yt-dlp ffmpeg deno whisper-cpp
```

Для расшифровки речи нужны модели whisper.cpp в `data/models/`. Без них бот работает, просто не показывает кнопку «📝 Текст»:

```sh
mkdir -p data/models
curl -L -o data/models/ggml-large-v3-turbo-q5_0.bin https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-large-v3-turbo-q5_0.bin
curl -L -o data/models/ggml-silero-v5.1.2.bin https://huggingface.co/ggml-org/whisper-vad/resolve/main/ggml-silero-v5.1.2.bin
```

1. Создайте бота у [@BotFather](https://t.me/BotFather) и скопируйте токен.
2. `cp .env.example .env` и впишите токен в `BOT_TOKEN`.
3. `go run ./cmd/bot`

Остановка — `Ctrl+C`: бот перестаёт брать задачи, до 60 секунд ждёт текущие, а тем, кто стоял в очереди, пишет о перезапуске.

Проверить, качает ли YouTube с этой машины, можно без Telegram:

```sh
go run ./cmd/ytcheck https://youtu.be/jNQXAC9IVRw
go run ./cmd/ytcheck -format mp3 -cut 0:05-0:15 https://youtu.be/jNQXAC9IVRw
go run ./cmd/ytcheck -format txt -cut 1:00-3:00 https://youtu.be/D6iMH-_IGGs
```

## Как пользоваться

- Ссылка → карточка ролика → **MP4**, **MP3** или **📝 Текст** → качество (для MP4) → **весь ролик** или **фрагмент**.
- Ссылка и таймкоды одним сообщением: `https://youtu.be/XXXXXXXXXXX 1:30-2:45`.
- Без кнопок: `/mp3 ссылка [таймкоды]`, `/mp4 ссылка [таймкоды]` (720p, а если не проходит по лимиту — качество ниже).
- `/text ссылка [таймкоды]` — расшифровка речи без кнопок.
- `/cancel` — отменить задачу или выйти из диалога, `/help` — форматы таймкодов и лимиты.

**Расшифровка.** Звук скачивается как для MP3, речь распознаёт [whisper.cpp](https://github.com/ggml-org/whisper.cpp) прямо на этой машине, без внешних сервисов. Сначала бот определяет язык, потом расшифровывает с подсказкой на этом языке: без неё Whisper часто теряет знаки препинания. VAD-модель отбрасывает тишину и музыку, иначе Whisper начинает выдумывать текст. Результат приходит сообщениями (до 5, дальше — «в файле») и файлом `.txt`, где каждая фраза стоит со своим временем в ролике. На Apple M5 час речи распознаётся примерно за 3–4 минуты. Повторный запрос того же куска присылает из кэша только файл.

Таймкоды: `1:30-2:45`, `90-165`, `1:02:30-1:05:00`, `1:30-` (до конца), `-2:45` (с начала); разделитель — дефис, тире или пробел.

Админам (`ADMIN_IDS`) доступны `/stats`, `/allow ID`, `/disallow ID`, `/ban ID`, `/unban ID`, `/blockvideo ссылка`, `/unblockvideo ссылка`. Пока белый список пуст, бот отвечает всем; с первым `/allow` или непустым `ALLOWED_USERS` — только тем, кто в списке.

## Настройки

Все настройки — переменные окружения или строки в `.env`; полный список с пояснениями в [.env.example](.env.example).

| Переменная | По умолчанию | Что задаёт |
| --- | --- | --- |
| `BOT_TOKEN` | — | токен бота, обязателен |
| `WORKERS` | 2 | задач одновременно |
| `QUEUE_SIZE` | 20 | длина очереди |
| `USER_ACTIVE_JOBS` | 1 | активных задач на пользователя |
| `USER_DAILY_QUOTA` | 20 | задач на пользователя в сутки |
| `MAX_FILE_MB` | 48 | максимальный размер файла |
| `MAX_DURATION_MIN` | 60 | максимальная длительность ролика или фрагмента |
| `JOB_TIMEOUT` | 10 | минут на одну задачу |
| `PROXY_URL` | — | исходящий прокси для yt-dlp |
| `YTDLP_COOKIES_BROWSER`, `YTDLP_COOKIES_FILE` | — | аккаунт YouTube для роликов с возрастным ограничением: имя браузера, где выполнен вход, или файл `cookies.txt`. Используется только для таких роликов |
| `BOT_API_URL` | — | локальный Bot API server, чтобы поднять лимит файла до 2000 МБ |
| `WHISPER_MODEL` | `data/models/ggml-large-v3-turbo-q5_0.bin` | модель распознавания; пусто или `off` — расшифровка выключена |
| `WHISPER_VAD_MODEL` | `data/models/ggml-silero-v5.1.2.bin` | модель, отсекающая тишину и музыку; необязательна |
| `WHISPER_LANGUAGE` | `auto` | язык речи, `auto` — определять самому |
| `WHISPER_THREADS`, `WHISPER_PATH` | 4, `whisper-cli` | потоки и путь к программе |

## Устройство

```
cmd/bot/            точка входа, конфиг, корректная остановка
cmd/ytcheck/        проверка загрузки без Telegram («этап 0» из спецификации)
internal/bot/       диалог, клавиатуры, лимиты, жизнь задачи; все тексты — в texts.go
internal/transcribe/ распознавание речи через whisper.cpp, текст с таймкодами
internal/source/    интерфейс Source и реализация для YouTube (yt-dlp + ffmpeg)
internal/timecode/  разбор и проверка таймкодов
internal/queue/     очередь, воркеры, отмена, таймаут
internal/store/     кэш file_id, дневные квоты, списки доступа — один JSON-файл
```

Тесты: `go test ./...`. Они не ходят в сеть: Telegram и загрузчик подменены.

### Отличия от спецификации

- **Без Docker и bbolt** — по условию локального этапа. Хранилище — JSON-файл за тем же набором операций, так что замена на bbolt не затронет остальной код.
- **Фрагменты режет ffmpeg, запущенный ботом, а не `yt-dlp --download-sections`.** yt-dlp только выдаёт адреса потоков. Причина: соединение с серверами YouTube иногда зависает на минуты, а yt-dlp в режиме фрагментов не показывает прогресс и ждёт такое соединение бесконечно. Бот видит, что позиция не двигается 20 секунд, убивает попытку и повторяет её (до трёх раз), а готовый фрагмент проверяет на полноту.
- **Качество считается по меньшей стороне кадра**, а не по высоте: иначе вертикальные Shorts 1080×1920 не попадали бы ни в один вариант.
- **Варианты качества, которые не проходят по лимиту целиком, не скрываются**, а помечаются «только фрагмент»: лимиты считаются по фрагменту, и вырезать две минуты из длинного ролика в 1080p можно.
